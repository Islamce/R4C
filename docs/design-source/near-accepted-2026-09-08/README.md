# Canonical near-accepted design references

These two screenshots are the current source of truth for the KYNOX commercial CRM opportunity experience:

- `01-opportunity-detail.jpg` — opportunity detail, guided stage progression, activity timeline, and next action.
- `02-opportunities-worklist.jpg` — opportunities worklist, KPI strip, search, and dense table view.

Use these references for all future visual decisions. Earlier design explorations and responsive fallback plots are historical only and must not be used as implementation targets.

The references intentionally preserve the approved visual language: dark navy shell, cyan emphasis, compact right-side navigation, Arabic-first content with English toggle, restrained KPI density, and record-centric opportunity workflows.
