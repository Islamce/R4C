# R4C Commercial Screen Matrix

| Screen | Primary user | Primary decision | Primary object | Current issue | Required redesign | Data status |
|---|---|---|---|---|---|---|
| Command Center | Founder, CEO, Commercial Director | What threatens commercial outcome now? | Portfolio/project | Metrics and analytics compete with action | Executive situation header, decision queue, pulse, portfolio health, closing readiness | SNAPSHOT with governed-live operations below |
| Project portfolio | Commercial Director, Project Director | Which project needs intervention? | Project | Table shows values but weak blocker signal | Inline delivery, sales, inventory, demand, reservations, blockers, and drill-down | SNAPSHOT |
| Inventory explorer | Sales Manager, Sales Agent | Which unit should be sold or held? | Unit inventory | Dense controls and mixed browsing/action hierarchy | Persistent project/building/floor context, filters, status legend, clear reservation eligibility | SNAPSHOT in suite; live available units in operator workspace |
| Floor navigator | Sales Agent, Sales Manager | Where is availability concentrated? | Building/floor | Floor list is visually dense | Per-floor total, available, held/reserved, sold, exception state | SNAPSHOT |
| Selected unit | Sales Agent, Commercial Manager | Is this unit commercially actionable? | Unit commercial file | Long drawer lacks progressive disclosure | Overview, commercial, buyer activity, evidence, history sections with persistent action bar | SNAPSHOT in suite; live unit/pricing in operator workspace |
| Buyer/lead file | Sales Agent, Sales Manager | What must happen for this buyer to progress? | Buyer/lead | Current live UI is a form/list with no first-class buyer file | Identity, owner, stage, preferred unit, activity, consent, evidence, hold, reservation, blocker, next action | GOVERNED LIVE |
| Sales pipeline | Sales Manager, Sales Agent | Which opportunities need follow-up? | Lead pipeline | Empty/list state is operationally safe but visually passive | Stage overview plus operational list with owner, age, value where valid, exception, next action | GOVERNED LIVE |
| Reservation queue | Sales Manager, Finance/closing operator | Which holds/reservations can progress? | Hold/reservation | Controls exist but are buried after unit selection | Active holds, expiry, published price, payment plan, review gate, confirmation result | GOVERNED LIVE |
| Title-transfer queue | Closing operator, Finance | Which files are blocked or ready? | Transfer record | Readiness summary is separate from commercial urgency | Queue with unit, buyer, value, readiness, blocker, owner, age, status | SNAPSHOT presentation file; governed wording |
| Title-transfer file | Closing operator, authorized administrator | What evidence is missing and what action is allowed? | Transfer file | Good checklist and disclaimer, but long detail hierarchy | Transaction summary, readiness checklist, evidence timeline, controlled actions, audit state | SNAPSHOT presentation file; controlled government handoff |
| Live operator loading/restricted state | Sales Agent, Sales Manager | Can I operate and why is data unavailable? | Workspace state | Loading and no-access states need strong explanatory hierarchy | Shared loading, empty, restricted, error primitives with retry/permission messaging | GOVERNED LIVE state |
